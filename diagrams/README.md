TASCA 2.2 – Diagrames de seqüència UML

Descripció
Aquest projecte conté els diagrames de seqüència UML del procés d'autenticació d'una aplicació web (Flaskr).
Els diagrames representen els participants, els missatges i els diferents camins possibles durant el procés d'inici de sessió.

Diagrames

1. Esquelet del diagrama
Mostra els quatre participants i les seves línies de vida.



2. Happy path
Representa el procés d'inici de sessió quan les credencials són correctes.



3. Credencials invàlides
Representa què passa quan l'usuari introdueix credencials incorrectes.



4. Sistema no accessible
Representa el procés quan el servidor o la base de dades no estan disponibles.



5. Format del correu incorrecte
Representa què passa quan l'usuari introdueix un correu electrònic amb un format incorrecte.
