GLOSSARI

1. Backlog
Anglès: Backlog
Definició: És una llista amb totes les tasques que encara queden per fer en un projecte, ordenades segons la seva importància o prioritat.
Exemple: Vam afegir al backlog les tasques que encara ens quedaven pendents.

2. Branca
Anglès: Branch
Definició: És una línia de treball separada que permet fer canvis o provar noves idees sense afectar directament la resta del projecte.
Exemple: Vam crear una branca nova per treballar en una funcionalitat.

3. Clon
Anglès: Clone
Definició: És una còpia d'un repositori que descarreguem a l'ordinador per poder treballar-hi directament.
Exemple: Vam clonar el repositori per modificar els fitxers des del nostre ordinador.

4. Commit
Anglès: Commit
Definició: És un registre dels canvis que hem fet als fitxers i que volem guardar a l'historial del projecte.
Exemple: Vam fer un commit després d'actualitzar el glossari.

5. Fork
Anglès: Fork
Definició: És una còpia d'un repositori que es crea al nostre compte de GitHub. Ens permet treballar-hi pel nostre compte sense modificar el repositori original.
Exemple: Vam fer un fork de pallets/flask per poder-hi fer canvis.

6. Git
Anglès: Git
Definició: És una eina que permet guardar un historial dels canvis que fem en un projecte i recuperar versions anteriors quan cal.
Exemple: Utilitzem Git per controlar els canvis que fem al codi.

7. GitHub
Anglès: GitHub
Definició: És una plataforma en línia on podem guardar repositoris Git i treballar en projectes amb altres persones.
Exemple: Vam pujar el fitxer GLOSSARI.md a GitHub perquè tothom el pogués consultar.

8. GitHub Projects
Anglès: GitHub Projects
Definició: És una eina de GitHub que serveix per organitzar les tasques d'un projecte, veure com avancen i planificar la feina.
Exemple: Vam crear un projecte a GitHub Projects per repartir les tasques entre els membres de l'equip.

9. Iteració
Anglès: Iteration
Definició: És un període de treball en què es fan un conjunt de tasques per avançar a poc a poc cap a un objectiu.
Exemple: Vam repartir les tasques en diferents iteracions per organitzar millor la feina.

10. Issue
Anglès: Issue
Definició: És un element que permet apuntar una tasca pendent, un error o una idea per millorar el projecte.
Exemple: Vam crear una issue per fer el seguiment d'una tasca pendent.

11. Kanban
Anglès: Kanban
Definició: És una manera visual d'organitzar les tasques en columnes, segons si estan pendents, en procés o acabades.
Exemple: Vam utilitzar un taulell Kanban per veure com avançaven les tasques.

12. Merge
Anglès: Merge
Definició: És l'acció d'unir els canvis d'una branca amb una altra per integrar la feina feta.
Exemple: Vam fer un merge per incorporar els canvis a la branca principal.

13. Pull request
Anglès: Pull request
Definició: És una proposta per revisar uns canvis abans d'afegir-los a una altra branca del projecte.
Exemple: Vam obrir una pull request perquè els companys revisessin els canvis abans d'integrar-los.

14. Repositori
Anglès: Repository
Definició: És un espai on es guarden els fitxers d'un projecte i l'historial de tots els canvis que s'hi han fet.
Exemple: Vam guardar els fitxers del projecte al repositori de GitHub.

15. Sprint
Anglès: Sprint
Definició: És un període curt de treball, normalment d'una a quatre setmanes, durant el qual l'equip intenta assolir un objectiu concret.
Exemple: Vam decidir quines tasques volíem acabar durant el sprint.

16. Sprint backlog
Anglès: Sprint backlog
Definició: És el conjunt de tasques que l'equip escull del backlog general per treballar-hi durant un sprint.
Exemple: Vam seleccionar les tasques del sprint backlog abans de començar el sprint.

17. Status
Anglès: Status
Definició: És el camp que indica en quin punt es troba una tasca, per exemple, si està pendent, en curs, en revisió o acabada.
Exemple: Vam canviar l'estat de la tasca a «acabada» quan vam completar-la.

18. Workflow
Anglès: Workflow
Definició: És el conjunt de passos que seguim per completar una tasca o dur a terme un procés de manera ordenada.
Exemple: Vam definir un workflow per saber quins passos havíem de seguir per comprovar el projecte.
